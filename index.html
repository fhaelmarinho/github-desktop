Tags HTML

<Header>

A Tag 'Header' define as informações do cabeçalho do site

<H1>, <H2>, <H3>, <H4>, <H5>, <H6>

As Tags '<H1> ... <H6>' definem o hierarquia dos títulos do mais importante para o título de menor importância

<body>

A Tag 'body' define o corpo principal do site, onde todas as informações visíveis para o usuário no navegador são registradas

<section>

A Tag 'section' Cria uma seção no site para agrupar o conteúdo

<div>

A Tag 'div' cria divisões do conteúdo

<ul>

A Tag 'ul' cria uma lista não-ordenada

<ol>

A Tag 'ol' cria uma lista ordenada
